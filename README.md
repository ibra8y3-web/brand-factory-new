# 🚀 مختبر الهندسة العكسية وتحليل الأكواد (Logic Reverse Lab)

منصة متطورة تعتمد على الذكاء الاصطناعي لتحليل المشاريع البرمجية الضخمة، فهم بنيتها، وإعادة كتابتها أو تحويلها إلى لغات برمجة أخرى بكفاءة عالية وبدون فقدان للبيانات.

## ✨ المميزات الرئيسية

* **📂 دعم المشاريع الكاملة (ZIP):** يمكنك رفع مشروع برمجي كامل بصيغة ZIP، وسيقوم النظام بفك ضغطه وقراءة جميع الملفات وتجاهل الملفات غير الضرورية (مثل `node_modules` والصور).
* **🧠 تحليل البنية المعمارية:** يقوم الذكاء الاصطناعي بقراءة المشروع واستخراج المنطق البرمجي، مع رسم مخططات تفاعلية (Mermaid.js) توضح تدفق البيانات (Data Flow).
* **🔄 المعالجة التدريجية (Chunking):** للتعامل مع المشاريع الضخمة التي تتجاوز حدود الذكاء الاصطناعي (Token Limits)، يقوم النظام بمعالجة وتحويل المشروع **ملفاً تلو الآخر** لتجنب أي أخطاء أو انقطاع.
* **💾 ذاكرة حديدية (IndexedDB):** جميع الملفات المرفوعة والمحولة يتم حفظها تلقائياً في ذاكرة المتصفح العميقة. 
  * مقاومة لتحديث الصفحة (Refresh).
  * مقاومة لإغلاق المتصفح.
  * يمكنك العودة في أي وقت واستكمال العمل من حيث توقفت.
* **⏸️ الإيقاف والاستكمال (Pause & Resume):** تحكم كامل في عملية التحويل، يمكنك إيقاف العملية مؤقتاً واستكمالها لاحقاً بضغطة زر.
* **📦 تصدير المشروع:** بعد انتهاء التحويل، يمكنك تحميل المشروع الجديد بالكامل كملف ZIP جاهز للعمل.

## 🛠️ التقنيات المستخدمة

* **إطار العمل:** React 18 + TypeScript + Vite
* **التصميم والواجهات:** Tailwind CSS + Framer Motion + Lucide React
* **التعامل مع الملفات:** JSZip (لفك وضغط الملفات)
* **قاعدة البيانات المحلية:** idb-keyval (IndexedDB) لحفظ حالة المشروع محلياً
* **الذكاء الاصطناعي:** مدمج مع واجهة برمجة تطبيقات مخصصة (Brand API) للتحليل والتحويل.

## 🚀 طريقة التشغيل محلياً

1. **تثبيت الحزم والاعتماديات:**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```

3. افتح المتصفح على الرابط `http://localhost:3000` (أو المنفذ المحدد في موجه الأوامر).

## 💡 كيف يعمل النظام؟

1. **الرفع:** قم برفع ملف ZIP يحتوي على الكود المصدري.
2. **التحليل:** سيقوم النظام بإنشاء ملخص للمشروع ورسم مخطط بياني يوضح كيفية عمله.
3. **التحويل:** حدد لغة البرمجة المستهدفة (مثلاً: من Python إلى Node.js)، وسيبدأ النظام في تحويل الملفات واحداً تلو الآخر.
4. **الاستكمال:** إذا انقطع الاتصال أو قمت بتحديث الصفحة، اضغط على "استكمال التحويل" ليقوم النظام بتخطي الملفات المنجزة وإكمال الباقي.
5. **التحميل:** اضغط على "تحميل المشروع (ZIP)" للحصول على الكود الجديد.
